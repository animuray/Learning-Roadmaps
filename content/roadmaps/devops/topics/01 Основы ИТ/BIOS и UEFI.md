# BIOS и UEFI

**Прошивка материнской платы** — первая программа, которая запускается после нажатия кнопки питания. Она проверяет железо, находит загрузчик и передаёт ему управление. От её настроек зависит, загрузится ли ОС, заработает ли виртуализация и пройдёт ли установка Windows 11.

## Путь от кнопки до ОС

1. Блок питания выдаёт стабильные напряжения, процессор начинает выполнять код прошивки.
2. **POST** (Power-On Self-Test) — самотестирование: процессор, память, видео. При фатальной ошибке плата пищит или мигает кодом.
3. Прошивка перебирает устройства по **порядку загрузки** (boot order).
4. Находит **загрузчик**: в режиме BIOS — в первом секторе диска (MBR), в режиме UEFI — файл `.efi` на специальном разделе ESP.
5. Загрузчик (Windows Boot Manager, GRUB, systemd-boot) загружает **ядро ОС**, дальше работает уже операционная система.

## BIOS (Legacy)

- Появился в 1980-х, работает в 16-битном режиме процессора.
- Загружается только с диска с разметкой **MBR**:
  - первый сектор диска (512 байт): 446 байт кода загрузчика, таблица на **4 основных раздела** и подпись;
  - больше разделов — через расширенный раздел с логическими дисками;
  - адресует диски максимум до **2 ТиБ** (при секторах по 512 байт).

## UEFI

Современная замена BIOS. На всех компьютерах последних десяти с лишним лет стоит UEFI, иногда с режимом совместимости.

- Работает с разметкой **GPT**: до 128 разделов, практически без ограничения на размер диска, есть **резервная копия таблицы в конце диска** и контрольные суммы CRC32.
- Загрузчики лежат как обычные файлы на **ESP** (EFI System Partition) — небольшом разделе с файловой системой **FAT32**. Например, `\EFI\Microsoft\Boot\bootmgfw.efi` или `/EFI/ubuntu/shimx64.efi`.
- Загрузочные записи хранятся в энергонезависимой памяти платы (**NVRAM**): можно иметь несколько ОС и выбирать между ними.
- **Secure Boot** проверяет цифровую подпись загрузчика и не даёт запустить неподписанный или подменённый код.
- **CSM** (Compatibility Support Module) — режим совместимости, эмулирует старый BIOS. На новых платах его часто уже нет.
- Умеет загружаться по сети (PXE, HTTP Boot), имеет графический интерфейс с мышью.

> [!important] Режим загрузки и разметка должны совпадать
> UEFI загружается с GPT, Legacy BIOS — с MBR. Если поставить ОС в одном режиме, а потом переключить прошивку в другой, система не загрузится. В Windows есть утилита `mbr2gpt` для перевода без переустановки.

## Настройки, которые нужны сисадмину

- **Порядок загрузки** и разовое меню загрузки (обычно F8, F11 или F12) — чтобы загрузиться с флешки или по сети.
- **Аппаратная виртуализация**: **Intel VT-x** или **AMD-V (SVM)**. Без неё не работают Hyper-V, VirtualBox с 64-битными гостями, KVM.
- **TPM** (или Intel PTT, AMD fTPM) — нужен для Windows 11 и BitLocker.
- **Secure Boot** — включить или выключить (некоторые Linux-драйверы и старые системы без подписи не грузятся).
- Режим SATA-контроллера: **AHCI** или RAID.
- **Wake-on-LAN** — включение по сети, **пароль на вход в настройки**.
- Дата и время прошивки — от них зависит проверка сертификатов.

## Батарейка CMOS и сброс настроек

Батарейка CR2032 на плате питает **часы реального времени** и память настроек, когда компьютер обесточен. Признак севшей батарейки: при каждом включении сбивается время, слетают настройки. Сбросить настройки прошивки можно перемычкой **Clear CMOS** или вынув батарейку на минуту.

## Как узнать режим загрузки

**Windows**: `msinfo32` → строка «Режим BIOS»: UEFI или «Устаревший». Тип разметки — в «Управлении дисками» → свойства диска → «Тома».

**Linux**:

```bash
ls /sys/firmware/efi       # каталог есть — система загружена в режиме UEFI
efibootmgr -v              # загрузочные записи UEFI
sudo fdisk -l /dev/sda     # Disklabel type: gpt или dos (MBR)
lsblk -f                   # найти ESP: раздел vfat, часто смонтирован в /boot/efi
```

## Обновление прошивки

Обновления закрывают уязвимости и добавляют поддержку новых процессоров. Но прерванная прошивка может «окирпичить» плату, поэтому шьют только **от стабильного питания** (лучше через ИБП) и **только файлом с сайта производителя** для точной модели платы. У серверов прошивку обновляют через BMC (iDRAC, iLO) — подробнее в теме [[Устройство компьютера]].

## Практика

- [ ] Узнать, в каком режиме загружен ваш компьютер: `msinfo32` в Windows или `ls /sys/firmware/efi` в Linux
- [ ] Посмотреть тип разметки своего диска: GPT или MBR
- [ ] Зайти в настройки UEFI своего ПК и найти: порядок загрузки, виртуализацию (VT-x/AMD-V), TPM и Secure Boot
- [ ] В VirtualBox создать ВМ, включить EFI в настройках, загрузить с ISO и сравнить с обычным режимом

## Тест

### Что делает POST при включении компьютера?
- [ ] Загружает ядро операционной системы
- [x] Проверяет основное оборудование: процессор, память, видео
- [ ] Обновляет прошивку
- [ ] Монтирует файловые системы
> POST — Power-On Self-Test. Если он находит фатальную ошибку, загрузка останавливается, а плата сообщает код сигналом или индикатором.

### Какое ограничение по размеру диска у разметки MBR (при секторах 512 байт)?
- [ ] 128 ГБ
- [x] 2 ТиБ
- [ ] 16 ТиБ
- [ ] Ограничения нет
> MBR хранит адреса секторов 32-битными числами: 2³² × 512 байт = 2 ТиБ. Для дисков больше нужен GPT.

### Сколько основных (primary) разделов поддерживает MBR?
- [ ] 2
- [x] 4
- [ ] 16
- [ ] 128
> Таблица разделов в MBR рассчитана на 4 записи. Больше — через расширенный раздел с логическими дисками.

### Что относится к UEFI?
- [x] Загрузка с дисков с разметкой GPT
- [x] Раздел ESP с файловой системой FAT32 и файлами загрузчиков .efi
- [x] Secure Boot
- [ ] Работа в 16-битном режиме процессора
- [ ] Загрузчик в 446 байтах первого сектора диска
> Последние два пункта — особенности старого BIOS и MBR.

### Что делает Secure Boot?
- [ ] Шифрует системный диск
- [x] Проверяет цифровую подпись загрузчика и не запускает неподписанный код
- [ ] Ставит пароль на вход в настройки прошивки
- [ ] Защищает от перегрева
> Шифрованием диска занимается BitLocker или LUKS. Secure Boot защищает цепочку загрузки от подмены.

### VirtualBox сообщает, что аппаратная виртуализация недоступна. Что включить в настройках UEFI?
- [ ] Secure Boot
- [ ] CSM
- [x] Intel VT-x или AMD-V (SVM)
- [ ] Wake-on-LAN
> Аппаратная виртуализация часто выключена по умолчанию. Без неё гипервизоры не запускают 64-битные ВМ или работают очень медленно.

### На ПК при каждом включении сбивается дата и время. Вероятная причина?
- [ ] Неисправен жёсткий диск
- [x] Села батарейка CMOS на материнской плате
- [ ] Не включён Secure Boot
- [ ] Неправильная разметка диска
> Батарейка CR2032 питает часы реального времени, пока компьютер обесточен. Неверное время ломает, например, проверку HTTPS-сертификатов.

### Что такое ESP?
- [ ] Энергосберегающий режим процессора
- [x] Раздел с файловой системой FAT32, где лежат загрузчики UEFI
- [ ] Резервная копия таблицы GPT
- [ ] Чип, где хранится прошивка
> EFI System Partition обычно занимает 100–600 МБ. В Linux его монтируют в `/boot/efi` или `/boot`.

### Какой каталог существует в Linux только при загрузке в режиме UEFI?
= /sys/firmware/efi
> Если `ls /sys/firmware/efi` выдаёт ошибку «нет такого файла», система загружена в режиме Legacy BIOS.

### Какая утилита Linux показывает и меняет загрузочные записи UEFI?
= efibootmgr
> `efibootmgr -v` показывает записи и порядок загрузки. Им же можно добавить или удалить запись.

### Что такое CSM в настройках UEFI?
- [ ] Модуль шифрования
- [x] Режим совместимости, который эмулирует старый BIOS для загрузки с MBR
- [ ] Контроллер SATA-дисков
- [ ] Система мониторинга температур
> CSM нужен для старых ОС и загрузочных носителей без поддержки UEFI. С ним не работает Secure Boot.

### Где GPT хранит резервную копию таблицы разделов?
- [ ] В NVRAM материнской платы
- [ ] На разделе ESP
- [x] В конце диска
- [ ] Резервной копии нет
> Основная таблица — в начале диска, копия — в последних секторах. Если начало диска повреждено, таблицу можно восстановить.
