# Терминал и базовые команды

**Терминал** — окно, в котором вы печатаете команды. **Оболочка** (shell) — программа внутри него, которая читает команды и запускает их. В большинстве дистрибутивов это **bash**; на macOS и у многих разработчиков — zsh. Команды из этой темы одинаково работают везде.

## Приглашение и устройство команды

```
user@server:~/projects$ ls -la /etc
```

- `user@server:~/projects$` — **приглашение**: кто вы, на какой машине и в каком каталоге. `$` — обычный пользователь, `#` — root.
- `ls` — команда, `-la` — **опции** (флаги), `/etc` — **аргумент**.
- Короткие опции можно склеивать: `ls -l -a` = `ls -la`. Длинные пишутся через два дефиса: `ls --all`.

## Пути

- **Абсолютный** путь начинается с `/` — от корня: `/var/log/nginx/access.log`.
- **Относительный** — от текущего каталога: `logs/app.log`.
- `~` — домашний каталог (`/home/user`), `.` — текущий каталог, `..` — родительский.
- Имена в Linux **чувствительны к регистру**: `File.txt` и `file.txt` — разные файлы.
- Имя с пробелами берут в кавычки: `cd "My Documents"`.

## Навигация

```bash
pwd                 # где я? (print working directory)
cd /etc             # перейти по абсолютному пути
cd ..               # на уровень выше
cd ~  или просто cd # домой
cd -                # в предыдущий каталог
ls                  # содержимое каталога
ls -l               # подробно: права, владелец, размер, дата
ls -la              # плюс скрытые файлы (имя начинается с точки)
ls -lh              # размеры в удобном виде: K, M, G
ls -lt              # сортировка по времени изменения
```

## Файлы и каталоги

```bash
mkdir backup                 # создать каталог
mkdir -p app/config/dev      # создать вместе с родительскими
touch notes.txt              # создать пустой файл (или обновить время изменения)
cp file.txt copy.txt         # копировать файл
cp -r src/ src-backup/       # копировать каталог рекурсивно
mv old.txt new.txt           # переименовать
mv file.txt /tmp/            # переместить
rm file.txt                  # удалить файл
rm -r dir/                   # удалить каталог с содержимым
rmdir empty-dir              # удалить только пустой каталог
```

> [!warning] rm -rf
> `rm` удаляет **без корзины** и без вопросов. `-r` — рекурсивно, `-f` — без подтверждений и без ошибок на отсутствующие файлы. Перед `rm -rf` всегда проверяйте путь через `ls`. Особенно опасны пути из переменных: если переменная окажется пустой, `rm -rf "$DIR/"` превратится в `rm -rf /`.

Шаблоны (wildcards) раскрывает оболочка: `*` — любые символы, `?` — один символ.

```bash
ls *.log          # все файлы .log
rm report-202?.txt
```

## Просмотр файлов

```bash
cat file.txt         # вывести целиком (для коротких файлов)
less /var/log/syslog # постранично: пробел — вперёд, / — поиск, n — следующее совпадение, q — выход
head -n 20 file      # первые 20 строк
tail -n 50 file      # последние 50 строк
tail -f app.log      # следить за файлом в реальном времени (Ctrl+C — выход)
```

## Справка

- `man ls` — подробное руководство (управление как в `less`, выход — `q`). `man -k слово` — поиск по описаниям.
- `ls --help` — краткая справка.
- `tldr ls` — короткие примеры (отдельная утилита, ставится пакетом).

## Горячие клавиши

| Клавиши | Действие |
| --- | --- |
| Tab | Дополнить команду или путь; двойной Tab — варианты |
| ↑ / ↓ | История команд |
| Ctrl+R | Поиск по истории |
| Ctrl+C | Прервать выполняющуюся команду |
| Ctrl+L | Очистить экран (как `clear`) |
| Ctrl+A / Ctrl+E | В начало / конец строки |
| Ctrl+D | Выйти из оболочки (конец ввода) |

`history` покажет историю, `!!` повторит последнюю команду — например, `sudo !!`, если забыли sudo.

## Тест

### Какая команда показывает текущий каталог?
= pwd
> print working directory.

### Что выведет ls -la по сравнению с обычным ls?
- [ ] Только каталоги
- [x] Подробный список (права, владелец, размер, дата), включая скрытые файлы
- [ ] Файлы, отсортированные по размеру
- [ ] Только скрытые файлы
> `-l` — подробный формат, `-a` — все файлы, включая начинающиеся с точки.

### Какой путь абсолютный?
- [ ] logs/app.log
- [ ] ../config
- [x] /var/log/app.log
- [ ] ./run.sh
> Абсолютный путь всегда начинается от корня `/`.

### Куда переведёт команда cd без аргументов?
- [ ] В корень /
- [x] В домашний каталог пользователя
- [ ] В предыдущий каталог
- [ ] Никуда, выдаст ошибку
> То же самое, что `cd ~`. В предыдущий каталог переводит `cd -`.

### Как создать каталог app/config/dev, если каталогов app и config ещё нет?
- [ ] mkdir app/config/dev
- [x] mkdir -p app/config/dev
- [ ] touch app/config/dev
- [ ] mkdir -r app/config/dev
> `-p` создаёт недостающие родительские каталоги и не ругается, если каталог уже есть.

### Как переименовать файл old.txt в new.txt?
- [ ] rename old.txt new.txt
- [ ] cp old.txt new.txt
- [x] mv old.txt new.txt
- [ ] rn old.txt new.txt
> В Linux переименование — это перемещение файла под новым именем.

### Чем опасна команда rm -rf?
- [x] Удаляет рекурсивно, без подтверждения и без корзины
- [x] Если путь собран из пустой переменной, можно удалить совсем не то
- [ ] Она удаляет файлы только после перезагрузки
- [ ] Она требует пароль root
> Проверяйте путь перед удалением, а в скриптах используйте `set -u` и проверки переменных.

### Как скопировать каталог src со всем содержимым в src-backup?
- [ ] cp src src-backup
- [x] cp -r src src-backup
- [ ] mv -r src src-backup
- [ ] copy src src-backup
> Без `-r` cp откажется копировать каталог.

### Как следить за новыми строками в логе app.log в реальном времени?
= tail -f app.log
= tail -F app.log
> `-F` дополнительно переоткрывает файл, если его заменили при ротации логов.

### Как найти слово в файле, открытом в less?
- [ ] Ctrl+F
- [x] Нажать / , ввести слово и Enter; n — следующее совпадение
- [ ] :find слово
- [ ] Только через grep
> Тот же поиск работает в `man`, потому что он показывает страницы через `less`.

### Что означает символ # в конце приглашения командной строки вместо $?
- [ ] Включён режим комментариев
- [x] Вы работаете от имени root
- [ ] Предыдущая команда завершилась с ошибкой
- [ ] Терминал подключён по SSH
> Работая под root, будьте особенно внимательны: система не остановит опасную команду.

### Какая комбинация клавиш прерывает выполняющуюся команду?
- [ ] Ctrl+Z
- [x] Ctrl+C
- [ ] Ctrl+D
- [ ] Ctrl+X
> Ctrl+Z не прерывает, а приостанавливает процесс — об этом в теме про процессы.

### Как получить подробное руководство по команде cp?
= man cp
> Краткую справку даёт `cp --help`.
