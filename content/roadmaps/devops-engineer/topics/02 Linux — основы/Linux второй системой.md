# Linux второй системой

Почти вся инфраструктура работает на Linux: серверы, виртуальные машины в облаках, контейнеры, узлы Kubernetes. Поэтому Linux — самый важный и самый большой блок роадмапа. Лучший способ перестать бояться терминала — каждый день работать в Linux.

## Что такое Linux

- **Linux** — строго говоря, только **ядро**: управляет процессами, памятью, дисками, сетью и устройствами. Его создал Линус Торвальдс в 1991 году.
- Поверх ядра работают системные утилиты (многие из проекта GNU), командная оболочка, менеджер пакетов, графическое окружение.
- **Дистрибутив** — готовая сборка: ядро, программы, установщик, репозитории пакетов и правила обновления.

## Семейства дистрибутивов

| Семейство | Дистрибутивы | Пакеты | Где встречается |
| --- | --- | --- | --- |
| Debian | Debian, Ubuntu, Linux Mint, Astra Linux | `.deb`, `apt` | Очень много серверов и десктопов |
| Red Hat | RHEL, Fedora, Rocky Linux, AlmaLinux, CentOS Stream, РЕД ОС | `.rpm`, `dnf` | Корпоративные серверы, банки |
| Arch | Arch Linux, Manjaro | `pacman` | Энтузиасты; отличная вики-документация |

Для начала подойдёт **Ubuntu** или **Fedora**. На серверах вы чаще всего встретите Ubuntu Server, Debian, Rocky/AlmaLinux, а в российских компаниях и госсекторе — ещё Astra Linux, ALT и РЕД ОС.

**LTS** (Long Term Support) — версии с долгой поддержкой, например Ubuntu 24.04 LTS. На серверах используют именно их.

## Почему второй системой, а не в виртуалке

Виртуальная машина безопасна, но её легко закрыть и вернуться в привычную систему. Когда Linux — основная система для повседневных задач, приходится решать реальные проблемы: звук, драйверы, разрешение экрана, Wi-Fi. Пока вы их чините, вы учитесь читать логи, искать ошибки и работать в терминале. Именно это потом нужно на работе.

> [!note] Если второй системой поставить нельзя
> Например, рабочий ноутбук. Тогда используйте виртуальную машину (VirtualBox, VMware) или WSL2 в Windows, но заставляйте себя делать в ней максимум задач.

## Установка рядом с Windows: план

1. **Сделайте резервную копию** важных данных. Разметка диска — операция, после которой бывает поздно жалеть.
2. Если включён **BitLocker** — сохраните ключ восстановления. Лучше временно отключить шифрование раздела, который будете уменьшать.
3. Отключите **быструю загрузку** (Fast Startup) в Windows. Иначе Windows не завершает работу полностью, и её раздел может оказаться недоступен или повреждён.
4. В «Управлении дисками» Windows **сожмите том** и оставьте неразмеченное место — от 50 ГБ.
5. Скачайте ISO-образ с официального сайта дистрибутива и запишите его на флешку программой balenaEtcher, Rufus или Ventoy. Просто скопировать ISO на флешку нельзя.
6. Перезагрузитесь и выберите флешку в **boot menu** (обычно F12, F11, F10, Esc или F2 — зависит от производителя).
7. Запустите **live-режим** («Попробовать Ubuntu») и проверьте, что работают Wi-Fi, звук и тачпад.
8. В установщике выберите «Установить рядом с Windows» или вручную укажите неразмеченное место.
9. После установки при загрузке появится меню **GRUB** с выбором системы.

> [!warning] Secure Boot
> Ubuntu и Fedora работают с включённым Secure Boot. Некоторым дистрибутивам и драйверам (например, проприетарному драйверу NVIDIA) нужна регистрация ключа (MOK) или отключение Secure Boot.

## Как жить в Linux каждый день

- Делайте обычные дела: браузер, мессенджеры, музыка, файлы. Всё, что можно, — через терминал.
- Когда что-то сломалось, ищите причину, а не переустанавливайте систему:
  ```bash
  journalctl -b -p err        # ошибки текущей загрузки
  sudo dmesg | tail -50       # сообщения ядра: драйверы, USB, диски
  lspci -k                    # устройства и их драйверы
  lsusb                       # USB-устройства
  ubuntu-drivers devices      # рекомендуемые драйверы (Ubuntu)
  ```
- Копируйте текст ошибки дословно в поиск или нейросеть, читайте Arch Wiki — она полезна для любого дистрибутива.
- Просите нейросеть давать вам задачи («придумай 10 упражнений на права доступа») и проверять решения.
- Записывайте, что сломалось и как починили, в репозиторий-конспект.

- [ ] Командная оболочка
> Всё остальное — утилиты, оболочка, менеджер пакетов, графика — собирают вместе с ядром в дистрибутив.

### Что такое дистрибутив Linux?
- [ ] Отдельная версия ядра
- [x] Готовая сборка: ядро, системные программы, установщик, менеджер пакетов и репозитории
- [ ] Программа для записи ISO на флешку
- [ ] Платная версия Linux
> Ubuntu, Debian, Fedora, Rocky Linux — разные дистрибутивы с одним ядром Linux внутри.

### Какие дистрибутивы относятся к семейству Debian?
- [x] Ubuntu
- [x] Linux Mint
- [ ] Rocky Linux
- [ ] Fedora
> Rocky Linux и Fedora — семейство Red Hat с пакетами .rpm и менеджером dnf.

### Каким менеджером пакетов устанавливают программы в Rocky Linux, AlmaLinux и Fedora?
- [ ] apt
- [x] dnf
- [ ] pacman
- [ ] brew
> В старых версиях RHEL и CentOS использовался yum; dnf — его преемник.

### Что означает LTS в названии Ubuntu 24.04 LTS?
- [ ] Light Terminal Session — облегчённая версия
- [x] Long Term Support — версия с долгим сроком поддержки и обновлений безопасности
- [ ] Linux Test System — тестовая сборка
- [ ] Версия только для серверов
> На серверах ставят LTS-версии: их не нужно обновлять до новой версии каждые полгода.

### Зачем перед установкой Linux рядом с Windows отключать быструю загрузку (Fast Startup)?
- [ ] Иначе Linux не увидит флешку
- [x] С быстрой загрузкой Windows не завершает работу полностью, и её раздел может быть недоступен или повредиться при доступе из Linux
- [ ] Иначе не будет работать интернет
- [ ] Это требование лицензии
> Fast Startup — по сути частичная гибернация: раздел Windows остаётся «занятым».

### Можно ли сделать загрузочную флешку, просто скопировав на неё ISO-файл?
- [ ] Да, этого достаточно
- [x] Нет, образ нужно записать специальной программой: balenaEtcher, Rufus, Ventoy
- [ ] Да, если флешка в формате NTFS
- [ ] Только для Fedora
> Запись образа создаёт на флешке загрузочную структуру; обычное копирование — просто файл.

### Что такое live-режим установочной флешки?
- [ ] Режим установки по сети
- [x] Запуск системы прямо с флешки без установки, чтобы проверить железо и попробовать систему
- [ ] Режим восстановления Windows
- [ ] Обновление BIOS
> Если Wi-Fi или звук не работают в live-режиме, лучше узнать это до установки.

### Что за меню появляется при загрузке компьютера после установки Linux рядом с Windows?
- [ ] BIOS Setup
- [x] Меню загрузчика GRUB с выбором операционной системы
- [ ] Диспетчер задач Windows
- [ ] Установщик Ubuntu
> GRUB подробно разбирается в теме «Загрузка Linux».

### Перед установкой Linux на диск с Windows, зашифрованный BitLocker, что нужно сделать в первую очередь?
- [ ] Ничего, BitLocker не мешает
- [x] Сохранить ключ восстановления BitLocker (а лучше временно отключить шифрование уменьшаемого раздела)
- [ ] Удалить Windows
- [ ] Отключить интернет
> Без ключа восстановления после изменения разметки можно потерять доступ к данным Windows.

### После установки не работает Wi-Fi. С чего правильнее начать?
- [ ] Сразу переустановить систему
- [x] Посмотреть сообщения ядра и устройства (dmesg, lspci -k, journalctl), найти драйвер и текст ошибки
- [ ] Вернуться на Windows
- [ ] Удалить все пакеты, связанные с сетью
> Диагностика по логам — главный навык, который даёт жизнь в Linux.

### Какая команда покажет ошибки текущей загрузки системы?
- [ ] ls -errors
- [x] journalctl -b -p err
- [ ] cat /boot
- [ ] systemctl reboot
> `-b` — текущая загрузка, `-p err` — приоритет «ошибка» и выше. Подробнее — в теме «Логи и journalctl».

### Почему роадмап советует ставить Linux второй системой, а не только в виртуальную машину?
- [ ] В виртуальной машине Linux работает иначе
- [x] Реальные проблемы с железом и ежедневные задачи заставляют разбираться в системе и привыкать к терминалу
- [ ] Виртуальные машины запрещены
- [ ] В виртуальной машине нет терминала
> Виртуалку легко закрыть и вернуться в Windows. Если такой возможности нет, привычка работать в терминале вырабатывается быстрее.
