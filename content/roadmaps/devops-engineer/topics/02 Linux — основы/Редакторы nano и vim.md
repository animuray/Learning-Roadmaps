# Редакторы nano и vim

На сервере нет графического интерфейса, а конфиги править нужно постоянно: `nginx.conf`, unit-файлы systemd, `sshd_config`, YAML-манифесты. Поэтому нужен хотя бы один консольный редактор. **nano** проще для старта, **vim** мощнее. А `vi` есть почти на любом сервере и в любом контейнере, даже там, где nano нет.

## nano

```bash
nano config.yml
nano -l config.yml   # с номерами строк
```

Подсказки по клавишам видны внизу экрана. `^` означает Ctrl, `M-` — Alt.

| Клавиши | Действие |
| --- | --- |
| Ctrl+O, Enter | Сохранить |
| Ctrl+X | Выйти (спросит про сохранение) |
| Ctrl+W | Поиск |
| Ctrl+K | Вырезать строку |
| Ctrl+U | Вставить |
| Alt+U / Alt+E | Отменить / повторить |
| Ctrl+_ | Перейти к строке по номеру |

## vim: главное — режимы

В vim клавиши работают по-разному в зависимости от режима. Это главное, к чему нужно привыкнуть.

| Режим | Как попасть | Зачем |
| --- | --- | --- |
| Normal (обычный) | Esc | Перемещение, удаление, копирование — клавиши здесь команды |
| Insert (вставка) | i, a, o | Набор текста |
| Visual (выделение) | v, V | Выделить символы или строки |
| Command-line | : из Normal | Сохранение, выход, замена, настройки |

Если не понимаете, что происходит, нажмите **Esc** несколько раз — вы вернётесь в Normal.

### Выйти из vim

| Команда | Действие |
| --- | --- |
| `:w` | Сохранить |
| `:q` | Выйти (если нет изменений) |
| `:wq` или `:x` | Сохранить и выйти |
| `:q!` | Выйти **без сохранения** |
| `ZZ` | Сохранить и выйти (из Normal) |

### Перемещение (Normal)

- `h j k l` — влево, вниз, вверх, вправо (стрелки тоже работают);
- `w` / `b` — слово вперёд / назад;
- `0` / `$` — начало / конец строки;
- `gg` / `G` — начало / конец файла; `:42` или `42G` — строка 42.

### Редактирование (Normal)

- `i` — вставка перед курсором, `a` — после курсора, `o` — новая строка ниже, `O` — выше;
- `x` — удалить символ, `dd` — удалить (вырезать) строку, `3dd` — три строки;
- `yy` — скопировать строку, `p` — вставить ниже;
- `u` — отменить, `Ctrl+R` — повторить отменённое;
- `.` — повторить последнее изменение.

### Поиск и замена

```vim
/listen          " поиск вперёд; n — следующее, N — предыдущее
:%s/8080/9090/g  " заменить во всём файле
:%s/old/new/gc   " то же с подтверждением каждой замены
:set number      " показать номера строк
```

Минимальный `~/.vimrc` для удобства:

```vim
set number
syntax on
set expandtab tabstop=2 shiftwidth=2   " пробелы вместо табов — важно для YAML
```

## Редактирование системных файлов

```bash
sudo nano /etc/ssh/sshd_config
sudoedit /etc/nginx/nginx.conf   # редактор от вашего пользователя, сохранение с правами root
```

Задать редактор по умолчанию (его откроют `git commit`, `crontab -e`, `visudo`):

```bash
export EDITOR=vim   # добавьте в ~/.bashrc
```

## Практика

- [ ] Открыть файл в nano, отредактировать, сохранить и выйти, не глядя в подсказки
- [ ] Пройти `vimtutor` целиком (около 30 минут; русская версия — `vimtutor ru`)
- [ ] Пройти тренажёр OpenVim

- [ ] Создать `~/.vimrc` с номерами строк и пробелами вместо табов
- [ ] Неделю править все файлы только в vim

## Тест

### Как сохранить файл и выйти из nano?
- [ ] :wq
- [x] Ctrl+O, Enter, затем Ctrl+X
- [ ] Ctrl+S, затем Ctrl+Q
- [ ] Esc, затем ZZ
> Символ `^` в подсказках nano означает Ctrl.

### В каком режиме vim находится сразу после открытия файла?
- [ ] Insert
- [x] Normal
- [ ] Visual
- [ ] Command-line
> В Normal нажатые клавиши — команды. Поэтому новички случайно что-то удаляют, начав печатать.

### Как в vim выйти без сохранения изменений?
= :q!
> `!` означает «принудительно, отбросив изменения».

### Как в vim сохранить файл и выйти?
- [x] :wq
- [x] :x
- [x] ZZ (в Normal-режиме)
- [ ] Ctrl+X
> Все три варианта сохраняют и закрывают файл.

### Какая клавиша в vim переводит из режима вставки в обычный режим?
- [ ] i
- [ ] Enter
- [x] Esc
- [ ] :
> Если запутались, нажмите Esc несколько раз.

### Что делает команда dd в обычном режиме vim?
- [ ] Дублирует строку
- [x] Удаляет (вырезает) текущую строку
- [ ] Удаляет символ под курсором
- [ ] Переходит в конец файла
> Вырезанную строку можно вставить клавишей `p`.

### Как в vim заменить 8080 на 9090 во всём файле?
- [ ] /8080/9090
- [x] :%s/8080/9090/g
- [ ] :replace 8080 9090
- [ ] s/8080/9090
> `%` — все строки, `g` — все вхождения в строке, а не только первое.

### Как в vim перейти в конец файла?
- [ ] gg
- [x] G
- [ ] $
- [ ] :end
> `gg` — в начало файла, `$` — в конец строки.

### Как отменить последнее изменение в vim?
- [x] u
- [ ] Ctrl+Z
- [ ] :undo!
- [ ] z
> Ctrl+Z в терминале приостановит сам vim и вернёт вас в оболочку; вернуться обратно можно командой `fg`.

### Какая клавиша в vim вставляет новую строку под текущей и сразу включает режим вставки?
= o
> `O` (заглавная) — новая строка над текущей.

### Почему стоит уметь пользоваться vi или vim, даже если вам удобнее nano?
- [ ] vim быстрее работает с сетью
- [x] vi есть почти на любом сервере и в минимальных образах, где nano может не быть
- [ ] nano не умеет сохранять файлы под root
- [ ] nano нельзя установить на сервер
> Умение хотя бы открыть файл, поправить строку и выйти из vi спасает в незнакомом окружении.

### Зачем в ~/.vimrc для DevOps часто включают expandtab?
- [ ] Чтобы ускорить vim
- [x] Чтобы клавиша Tab вставляла пробелы: в YAML табуляция для отступов запрещена
- [ ] Чтобы включить подсветку синтаксиса
- [ ] Чтобы показывать номера строк
> Ошибка «found character that cannot start any token» в YAML часто означает таб вместо пробелов.
