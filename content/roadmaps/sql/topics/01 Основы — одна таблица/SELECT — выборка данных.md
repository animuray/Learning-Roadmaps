# SELECT — выборка данных

`SELECT` — самая частая команда SQL. Отчёт для менеджера, проверка данных после релиза, поиск причины бага, выгрузка для аналитики — всё начинается с `SELECT`.

Во всех темах этого раздела используется одна таблица — товары интернет-магазина электроники:

| Столбец | Тип | Что хранит |
| --- | --- | --- |
| `id` | integer | номер товара, первичный ключ |
| `name` | text | название |
| `category` | text | категория: Смартфоны, Ноутбуки, Аудио… |
| `brand` | text | бренд; у части товаров `NULL` |
| `price` | integer | цена в рублях |
| `qty` | integer | остаток на складе |
| `added_at` | date | дата поступления в продажу |

Полные данные можно посмотреть в каждой задаче тренажёра — блок «Данные задачи».

## Выбор столбцов

```sql
SELECT name, price
FROM products;
```

- После `SELECT` — список столбцов **в том порядке, в котором они нужны в результате**.
- После `FROM` — таблица.
- `SELECT *` выводит все столбцы. Удобно для знакомства с данными, но в приложениях и отчётах перечисляйте столбцы явно: `*` тянет лишние данные, а результат меняется при каждом изменении таблицы.

Ключевые слова SQL не чувствительны к регистру: `select`, `SELECT` и `Select` — одно и то же. Принято писать их заглавными, а имена — строчными, так запрос легче читать. Точка с запятой в конце разделяет команды; для одиночного запроса она не обязательна.

## Псевдонимы — AS

```sql
SELECT name AS product, price AS price_rub
FROM products;
```

`AS` задаёт имя столбца в результате. Слово `AS` можно опустить (`SELECT name product`), но с ним понятнее. Если в псевдониме пробел или заглавные буквы — берите его в двойные кавычки: `AS "Цена, руб"`.

## Вычисляемые столбцы

В `SELECT` можно писать выражения, а не только имена столбцов:

```sql
SELECT name,
       price * qty        AS stock_value,   -- стоимость остатка
       price * 0.9        AS sale_price,    -- цена со скидкой 10 %
       'шт.'              AS unit,          -- константа в каждой строке
       name || ' — ' || category AS title   -- склейка строк
FROM products;
```

- Арифметика: `+ - * /` и `%` — остаток от деления.
- `||` склеивает строки. Если один из операндов `NULL`, результат тоже `NULL` (подробнее — в теме [[Выражения, функции и CASE]]).
- Выражение не меняет таблицу — оно считается только для результата запроса.

> [!warning] Целочисленное деление
> Если оба операнда целые, PostgreSQL делит нацело: `7 / 2` = `3`. Чтобы получить дробь, сделайте одно из чисел дробным: `7 / 2.0` = `3.5`, или `price / 90.0`.

Округление — функция `round(x, n)`: `round(1234.567, 2)` = `1234.57`, `round(1234.567)` = `1235`.

## Порядок выполнения запроса

Запрос пишется в одном порядке, а выполняется в другом:

| Пишем | Выполняется |
| --- | --- |
| 1. `SELECT` | 5 |
| 2. `FROM` | 1 — откуда берём строки |
| 3. `WHERE` | 2 — какие строки оставляем |
| 4. `GROUP BY` | 3 — как группируем |
| 5. `HAVING` | 4 — какие группы оставляем |
| 6. `ORDER BY` | 6 — сортируем результат |
| 7. `LIMIT` | 7 — обрезаем |

Отсюда практичное следствие: псевдоним из `SELECT` **нельзя** использовать в `WHERE` — на момент фильтрации он ещё не вычислен. А в `ORDER BY` — можно. Эту таблицу полезно помнить: на собеседованиях про неё спрашивают часто.

## Как читать ошибки

```
ERROR:  column "nam" does not exist
LINE 1: SELECT nam FROM products
               ^
```

PostgreSQL показывает, где именно ошибка: опечатка в имени столбца, пропущенная запятая между столбцами, строка в двойных кавычках вместо одинарных (`"Аудио"` база примет за имя столбца). Читайте сообщение целиком — в нём почти всегда ответ.

### Названия и цены

Выведите название и цену всех товаров (столбцы `name`, `price`).

```sql check
SELECT name, price FROM products;
```

```sql solution
SELECT name, price FROM products;
```

### Свой порядок столбцов

Выведите для всех товаров категорию, название и цену — именно в таком порядке столбцов.

```sql check
SELECT category, name, price FROM products;
```

```text hint
Результат: категория | название | цена.
Столбцы в результате идут в том порядке, в котором вы их перечислили.
```

```sql solution
SELECT category, name, price FROM products;
```

### Стоимость остатков

Для каждого товара выведите название и стоимость его остатка на складе (цена × количество). Второй столбец назовите `stock_value`.

```sql check
SELECT name, price * qty FROM products;
```

```sql solution
SELECT name, price * qty AS stock_value FROM products;
```

### Цена со скидкой

Выведите название, цену и цену со скидкой 15 %, округлённую до целых рублей функцией `round`.

```sql check
SELECT name, price, round(price * 0.85) FROM products;
```

```text hint
Для каждого товара: название | цена | цена со скидкой.
Цена со скидкой 15 % — это 85 % от цены, затем округлить до целых.
```

```sql solution
SELECT name, price, round(price * 0.85) AS sale_price FROM products;
```

### Цена в долларах

Выведите название и цену в долларах по курсу 90 рублей, округлённую до двух знаков после запятой.

```sql check
SELECT name, round(price / 90.0, 2) FROM products;
```

```text hint
Цена в долларах = цена ÷ 90, округлить до двух знаков.
Осторожно: если оба числа целые, PostgreSQL делит нацело и теряет копейки. Сделайте одно из чисел дробным.
```

```sql solution
SELECT name, round(price / 90.0, 2) AS price_usd FROM products;
```

### Подпись для витрины

Выведите один столбец: название и категорию в формате `Смартфон Nova 8 (Смартфоны)`.

```sql check
SELECT name || ' (' || category || ')' FROM products;
```

```text hint
Склеить в одну строку: название + « (» + категория + «)».
Скобки и пробел — тоже строки. Для склейки в PostgreSQL есть специальный оператор, он в конспекте.
```

```sql solution
SELECT name || ' (' || category || ')' AS title FROM products;
```

## Тест

### Что выведет `SELECT price, name FROM products`?
- [ ] Столбцы в порядке, как они описаны в таблице
- [x] Сначала цену, потом название
- [ ] Ошибку: столбцы нужно перечислять в порядке таблицы
- [ ] Только первую строку
> Порядок столбцов результата задаётся списком в SELECT.

### Почему в коде приложения не стоит писать `SELECT *`?
- [x] Запрос тянет лишние данные
- [x] Результат меняется, когда в таблицу добавляют или удаляют столбцы
- [ ] `SELECT *` работает только в psql
- [ ] `SELECT *` не возвращает строки с NULL
> Для разового просмотра данных `*` удобна, в коде — перечисляйте нужные столбцы.

### Чему равно `7 / 2` в PostgreSQL?
= 3
> Оба числа целые — деление нацело. Чтобы получить 3.5, пишут 7 / 2.0.

### Что делает `AS` в `SELECT price * qty AS total`?
- [ ] Создаёт новый столбец в таблице
- [x] Задаёт имя столбца в результате запроса
- [ ] Сохраняет результат в переменную
- [ ] Приводит значение к типу total
> Таблица не меняется, AS — только имя в выводе.

### Какая часть запроса выполняется первой?
- [ ] SELECT
- [x] FROM
- [ ] WHERE
- [ ] ORDER BY
> Порядок: FROM → WHERE → GROUP BY → HAVING → SELECT → ORDER BY → LIMIT.

### Почему запрос `SELECT price * qty AS total FROM products WHERE total > 1000` не работает?
- [ ] Нельзя умножать столбцы
- [x] WHERE выполняется раньше SELECT, псевдоним total там ещё не известен
- [ ] Псевдонимы работают только с AS в кавычках
- [ ] В WHERE нельзя использовать числа
> Нужно повторить выражение: WHERE price * qty > 1000 — или вынести его в подзапрос.

### Каким оператором склеиваются строки в PostgreSQL?
= ||
> Также есть функция concat(), которая, в отличие от ||, пропускает NULL.

### Что вернёт `SELECT 'Цена: ' || NULL`?
- [ ] 'Цена: '
- [ ] 'Цена: NULL'
- [x] NULL
- [ ] Ошибку
> Почти любая операция с NULL даёт NULL.

### Что вернёт `round(2.567, 1)`?
= 2.6

### В запросе `SELECT name, "Аудио" FROM products` ошибка. Какая?
- [ ] Нельзя выбирать константы
- [x] В двойных кавычках — имя столбца, а столбца «Аудио» нет; строку пишут в одинарных
- [ ] Кириллица в запросах запрещена
- [ ] Не хватает AS
> 'Аудио' — строка, "Аудио" — идентификатор.

### Какие из запросов корректны?
- [x] SELECT name, price * 2 AS double_price FROM products;
- [x] select name from products
- [ ] SELECT name price qty FROM products;
- [ ] SELECT FROM products name;
> В третьем варианте пропущены запятые: SQL поймёт `price` как псевдоним для name, а на qty выдаст ошибку.

### Как в результате назвать столбец «Цена, руб»?
- [ ] AS Цена, руб
- [ ] AS 'Цена, руб'
- [x] AS "Цена, руб"
- [ ] AS [Цена, руб]
> Имена с пробелами и знаками берут в двойные кавычки. Квадратные скобки — синтаксис SQL Server.
