# Learning Roadmaps — заметки для работы над проектом

- Язык интерфейса и контента — русский.
- Next.js 16 с изменениями API: перед правками роутинга, кеширования и серверных действий сверяйтесь с `node_modules/next/dist/docs/`. `cacheComponents` выключен намеренно: почти все страницы зависят от пользователя.
- Контент живёт в `content/` (хранилище Obsidian), формат — `content/README.md`. После правок контента запускайте `npm run content:check`, после правок задач SQL-тренажёра — ещё и `npm run sql:check` (нужна песочница: `npm run sql:setup`).
- Запросы ученика в тренажёре выполняются в песочнице (`src/lib/sql-practice.ts`): отдельная роль и база, транзакция с откатом, сторожевой таймер. На `statement_timeout` не полагаться — ученик может его отключить.
- Тема адресуется парой `roadmap` + `slug`. Slug — ключ прогресса в базе: в существующих темах его не меняем.
- Правильные ответы теста никогда не уходят в браузер до сдачи: проверка только в `submitQuiz` (`src/app/actions/learning.ts`).
- Лаборатории (`## Лаборатория`): проверка смотрит на состояние стенда, а не на команды; сообщения `fail` описывают, что не так, без команд и способа решения; setup повторяемый; после правок — `npm run lab:check` на стенде (`npm run lab:stand:wsl` + `npm run lab:runner`). Формат — `content/README.md`.
- Подсказки к задачам тренажёра — русский псевдокод по шагам, без SQL-кода и названий команд: готовый запрос есть в «Решении».
- Тесты к темам пишем по всему важному в теме, а не только по конспекту: понимание, команды, диагностика, практические ситуации. Банк вопросов больше, чем `quizSize`, у каждого вопроса — пояснение.
- После изменения `src/db/schema.ts`: `npm run db:generate` и закоммитить новую миграцию из `drizzle/`.
